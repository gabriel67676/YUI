# Atividade API de Produtos

## Descrição

Projeto desenvolvido para criar uma API com Node.js e Express e um frontend que utiliza Fetch para buscar os dados da API.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- CORS

## Estrutura do projeto

- Backend
  - package.json
  - server.js
- Frontend
  - index.html
  - style.css
  - script.js
- README.md

## Como executar

1. Entre na pasta Backend:

cd Backend

2. Inicie a API

node server.js

3. Abra o Frontend pelo live server

A API utiliza a porta 3000.
